# RMLink 10–20 MHz SWD 实机测试报告

测试日期：2026-11-17。主数据取自 00:29～00:34 的最终固件复测，时区 UTC+8。本报告整理已有实测记录，没有重新连接设备或烧录目标。

## 结论

在本台 ESP32-S3 RMLink、当前接线和 STM32H723VGT6 独立测试程序下，10/12/15/18/20 MHz 请求档均通过同一最终镜像的 32 轮 4 KiB SRAM 写读，内容比对正确，SWD 错误为零。

20 MHz 相对 10 MHz 的板内连续读取吞吐为 **1.40 倍**，离散读取为 **1.31 倍**；对应耗时减少 **28.6%/23.9%**。通过 Wi-Fi 服务执行的 4 KiB 调用中位数仍约为 100 ms，未呈现随 SWD 时钟单调提升的结果，不能把板内加速比例直接当作端到端加速。

20 MHz 另通过三次 128 KiB 烧录、FAULT 清除和两分钟并行采样。两分钟内检查 239974 帧，内容错误与 SWD 失败为零，但有 191 个调度序号缺口，因此未达到严格无丢帧。当前最高通过请求档为 20 MHz，CPU 标定估计约 19.20 MHz，默认连接时钟仍为 4 MHz。

## 设备、固件与方法

| 项目 | 条件 |
| --- | --- |
| 探针 | RMLink 二号机 `b81f3fc30470`，ESP32-S3，CPU 240 MHz |
| 连接 | Wi-Fi TCP，DAP 包长 512 字节，执行器 core0，TOS160 |
| 板型与引脚 | RMLink V1，SWDIO GPIO17、SWCLK GPIO18、NRST GPIO6 |
| 内存配置 | PSRAM 镜像缓存；原内部 RAM 采样环不变 |
| 目标 | STM32H723VGT6，独立测试程序，复位 HSI，无 PLL/Cache/外设初始化 |
| 固件版本与源码 | 0.3.4，最终实现对应提交 `61a2560` |
| 应用镜像 SHA256 | `6e0942857e33e1d1232691416fc1891a8327e58b1f284ed60aff7e4e18be9453` |
| ELF SHA256 | `9b887c74c968b215f2010bf4b82a364c905c09deaf284c25216c93baf7eb5e42` |

五档性能比较全部使用上述最终镜像与同一目标程序。每档暂停目标，在 AXI SRAM `0x24010000` 起的 4 KiB 区域写入全零、全一、交替位及确定随机数据，完整读回比对，共 32 轮，即每档 128 KiB 写入和 128 KiB 回读。

板内连续/离散读取均读取 1024 个 32 位字，地址步长分别为 4/64 字节，各运行三次取中位数，计时不包含 Wi-Fi/HTTP 往返。各档样本量较小，报告保留测量条件，不作统计显著性或长期可靠性推断。

“请求时钟”是配置值，“标定估计”来自 CPU 周期测量，包含少量入口/收尾开销。当前 RMT 诊断在 12 MHz 以上记录不完整，不能据其脉冲中位数宣称外部精确频率或模拟信号质量已通过验收。

本次可证实的是板内读取耗时下降。端到端调用没有取得同等比例收益，现有数据没有进一步分离各层耗时的贡献。

## 20 MHz 完整功能验证

最终镜像以 20 MHz 请求档连续执行三次 128 KiB 扇区擦写，每次都通过探针全量校验和主机独立回读比对，零 RAM 重试、无降频，复位后测试程序处于 Running、标识正确。

| 烧录指标，三次中位数 | 耗时 |
| --- | --- |
| 探针内擦写及校验 | 2.640 s |
| 其中擦除 | 0.934 s |
| 其中编程 | 1.388 s |
| 其中全量校验 | 0.291 s |
| 含上传、主机校验、复位的完整调用 | 4.834 s，三次范围 4.793～4.850 s |

FAULT 验证读取未映射地址 `0xfffffffc`，实际获得 FAULT 和 STICKYERR；清除后恢复正确的 DP ID、测试标识与运行态。没有重放应用内存写入。

连续采样使用十字段、500 µs 周期（请求 2 kHz），并行两字段、20 ms 周期快照，运行 120 s：

| 指标 | 结果 |
| --- | --- |
| 已检查主采样帧数 | 239974 |
| 内容错误 / SWD 失败 | 0 / 0 |
| 有效帧率 | 1998.41 Hz |
| 序号缺口 / 调度漏拍 | 191 / 191，约 0.080% |
| 探针环形缓冲丢弃 / 主机实时游标缺口 | 0 / 0 |
| 读超时恢复 / 读 FAULT 恢复尝试 | 0 / 0 |
| 快照调度漏拍 / 缓冲丢弃 / SWD 失败 | 0 / 0 / 0 |
| 采集跨度 p50/p95/p99 | 118/154/287 µs，仅末 65536 帧窗口 |

内容与 SWD 正确性通过，调度仍有跳拍。此次两分钟测试不能替代整夜运行，也不能据此认定前次十分钟测试出现的无线流丢帧已经解决。全部交付帧经过内容检查，归档保留示例帧、进度与汇总，没有保存全部原始帧值。
