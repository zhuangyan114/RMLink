# ESP32-S3 SWD 时钟与采样对照

0.2.15→0.2.16只修正Xtensa慢速延时循环的周期系数：由继承的3改为4。debug_probe原本就以-O2编译，主应用仍保留原构建配置。默认请求4 MHz不变，USB和无线使用同一内核。

RMT观察GPIO5数字输入，参考80 MHz、每tick12.5 ns；每档位的空闲零序列及DP ID读取各3次，测量后检查CPUID、运行状态，最终完整64 KiB Flash SHA256一致。不是外部仪器或目标端模拟波形验证。

| --- | ---: | ---: |
| 100 kHz | 74.77 kHz | 99.63 kHz |
| 1 MHz | 0.727 MHz | 0.964 MHz |
| 2 MHz | 1.404 MHz | 1.860 MHz |
| 4 MHz | 2.667 MHz | 3.200 MHz |

每版54轮指针矩阵：相同F103C8 fixture、十个动态32位字段、叶节点相隔64 B、每轮3 s、每布局3次、请求period=1000 us。下列均与Watch前四字段/100 ms及RTT/5 ms共存，报告三次有效帧率中位。共享链与独立链不可混用。

完整矩阵无无效帧、消费者缺口和非预期SWD失败；另有刻意的空指针/越界/未对齐/有符号偏移负向检查，不能将其预期failure计数当作吞吐测试故障。帧包含多次目标读取，不是原子快照；期限跳过、预算超限依然明确上报。此处不代表长时间无损，也未运行已安装VS Code界面。

原始记录在artifacts/logs的pointer-matrix-0215/0216.json及probe-diagnostics-idle-ready-0215/probe-diagnostics-version-final-0216.json；实际刷入身份以receipt和最终检查点清单为准。0.2.16同时将厂商查询版本自动绑定CMake应用版本，连接服务在实际建立承载时更新已配对设备的固件元数据，避免升级后一直显示旧版本。

## 0.2.17 固定时序开销校准

保留循环系数4，将Xtensa固定半周期开销保守计入4个CPU周期，避免只按一次GPIO写入估计。实测DP读取：100 kHz→99.88 kHz、1 MHz→0.988 MHz、2 MHz→1.951 MHz、4 MHz→3.636 MHz；空闲序列4 MHz请求约3.478 MHz。24次测量后的CPUID、状态及完整Flash比较通过。仍不宣称目标端模拟信号已验收。

相同54轮矩阵的共存中位：静态991.22 Hz、共享三级933.72 Hz、独立三级332.91 Hz、独立四级323.37 Hz、共享四级907.46 Hz。0.2.15/16/17测量为相邻批次，各布局3次×3 s；控制背景、噪声和期限网格会影响跨版本差值。

0.2.17一小时独立四级十字段共存实测328.30 Hz，1544458帧录制独立CRC／哈希／字段检查通过，板端SWD failures/ring_dropped、消费者缺口、无效数据均0，十叶节点各变化326614次。Timeline请求周期1 ms，实际跨度约3 ms，存在241万次请求期限跳过；这是未执行的采样槽位，不是TCP丢包。记录SHA256 `55fdcb7e00f1761b9e3ff39fa133ea230e5f4e3321806095182d178598be0d78`。

## 五个三级指针与五个普通变量

用户追加的实际组合：五个字段各解引用三级指针、另外五个字段直接寻址，共十个动态32位叶节点，地址间隔64 B。比较独立链及共享链；每条件三次×5 s，顺序交替，共24轮。SWD请求4 MHz，原固件和目标程序不变。共存条件为Watch前四字段/100 ms、RTT/5 ms。

| 指针布局 | 单独/1000 Hz请求 | 单独/5000 Hz请求 | 共存/1000 Hz请求 | 共存/5000 Hz请求 |
| --- | ---: | ---: | ---: | ---: |
| 五条独立三级链 | 498.08 | 689.83 | 499.02 | 676.22 |
| 共享一条三级链 | 948.44 | 1179.50 | 951.89 | 1139.74 |

单位均为实际完整帧Hz。全部无无效帧、消费者缺口、板端SWD失败和缓存丢弃；请求期限跳过仍存在。独立链共存帧内跨度P50约1275 us，共享链约693 us，均超过5000 Hz的200 us预算。提高请求频率减少等待下一个采样槽位，提高实际频率，不会消除SWD读取成本。独立组合每帧至少25个物理32位读取；共享链经帧内去重约13个。普通变量在本次为离散地址，不可直接套用于连续数组或具体应用。

原始记录：`mixed-5ptr3-5direct-1k-5k-0217.json`。新增`benchmark_mixed_subscriptions.py`可复现该对照；持续脚本支持`--pointer-depth 3 --independent --direct-fields 5 --period-us 200`。5 kHz是本次显式采样请求，未全局改动其他订阅默认值或SWD默认值。
