# 修复与功能记录

这里按时间倒序记录每次修完 Bug 或加完新功能、并经你手动实测确认后的完整信息，方便日后回溯或对照。

## 记录约定

- **确认后才写正式条目**：必须等你明确确认“手动验证通过”之后，才写入本目录。每件事单独建一个 `YYYY-MM-DD-简短主题.md` 文件（日期用确认当天的日期），并在下方列表最顶部加一条入口。
- **写清楚来龙去脉**：包含确认日期与原话、遇到的问题或需求、根因或设计思路、改动方案与涉及文件。
- **固件改了就记摘要**：如果动了固件，写明设备 ID、芯片型号、版本号、构建配置和镜像/ELF SHA256，方便区分同版本号下的不同编译结果。
- **测试和实测分开写**：自动化单测、本机编译、实板检查和你的手动实测分开写清楚，测到哪一步就写到哪一步，没测过的项目不混写进去。
- **原始证据放 `artifacts/`**：日志、截图、数据包和备份只留在本地 `artifacts/` 目录，正文里标注路径，不进 Git。
